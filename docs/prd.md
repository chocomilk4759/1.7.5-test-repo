# 공업용 계산기 PRD

## 목표

공업용 계산기의 계산 엔진과 단위 변환을 외부 패키지 없는 JavaScript(ES 모듈)로 만든다. 결과 표시 규칙(`formatNumber`)은 이미 `src/number-format.js`에 있고 테스트가 있다. 계산기 화면은 글자를 돌려주는 순수 함수로 만들고, 브라우저 화면은 뒤 Epic에서 다룬다.

## Epic 1: 계산과 단위

### Story 1.1: 계산 엔진

1. `evaluate(expression)`은 수, `+` `-` `*` `/`, 괄호로 된 식의 값을 수로 돌려준다. 곱셈과 나눗셈은 덧셈과 뺄셈보다 먼저 계산하고, 우선순위가 같으면 왼쪽부터 계산한다.
2. 단항 마이너스(`-3`, `-(2 + 1)`, `2 * -3`)를 받는다. 수와 연산자 사이의 공백은 무시한다.
3. 0으로 나누기, 짝이 맞지 않는 괄호, 받지 않는 글자, 빈 식과 공백만 있는 식은 `CalculationError`를 던진다. 오류 메시지는 까닭과 문제가 된 위치를 담는다.
4. 결과는 배정밀도 수 그대로이며 `evaluate`는 반올림하지 않는다.

Depends on: none

### Story 1.2: 단위 변환

1. `convert(value, from, to)`는 같은 종류의 단위 사이에서 값을 바꿔 돌려준다. 종류와 단위는 길이(`mm`, `cm`, `m`, `km`, `in`, `ft`), 압력(`Pa`, `kPa`, `MPa`, `bar`, `psi`), 온도(`C`, `F`, `K`)다.
2. 온도는 원점이 다른 변환이다(예: 0 C = 32 F = 273.15 K).
3. 모르는 단위, 서로 다른 종류 사이의 변환, 유한한 수가 아닌 값, 절대 영도보다 낮은 온도는 `ConversionError`를 던진다.
4. `units(kind)`는 그 종류(`length`, `pressure`, `temperature`)의 단위 기호 목록을 AC 1의 순서로 돌려준다. 모르는 종류는 `ConversionError`를 던진다.

Depends on: none

### Story 1.3: 계산기 화면

1. `renderScreen(expression)`은 식과 결과를 `{식} = {결과}` 꼴의 한 줄 글자로 돌려준다. 결과는 `evaluate`로 계산하고 `formatNumber`로 표시한다.
2. 식이 `CalculationError`를 던지면 `renderScreen`은 던지지 않고 `오류: {메시지}` 한 줄을 돌려준다. 다른 오류는 그대로 던진다.
3. 빈 식과 공백만 있는 식은 빈 글자를 돌려준다.

Depends on: 1.1
